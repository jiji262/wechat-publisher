# 旧笔记本改成家庭服务器,第一年的账本

> 一台闲置五年的笔记本,装上 Linux 之后接管了家里的照片备份、下载和内网文档。它一开始只是周末拿来试试,后来每天早上家里第一个打开的页面就是它。**现在全家人的照片都存在这台机器上。**

## 一年下来记了什么

翻了一遍这一年的维护记录,按时间顺序是这几条:

1. 旧笔记本自带电池,停电时能多撑四十分钟
2. 机械硬盘换成固态之后,待机时几乎听不到声音
3. 全家用得最多的是照片备份,下载排第二
4. 内网文档放了家电说明书和保修卡照片
5. 每月电费比预想的低,一年加起来六十多元
6. 最费时间的是第一个周末的配置,之后每月只看一眼
7. **备份要单独花心思**——第二块硬盘是第三个月才补上的

## 三个变化

这一年家里存照片的地方 ==换了位置==。具体是:

- **存储位置**:从四部手机各存各的,到集中放在一台机器上
- **访问方式**:从用数据线拷来拷去,到局域网里直接打开
- **维护分工**:从谁的手机谁管,到 ++一个人管一台机器++

举个例子:以前找一张三年前的照片,要翻好几部手机;现在 %%打开相册页面按日期往下拉%%,一分钟内能找到。手机换新时,&&旧照片不用再导一遍&&。

### 电费和噪音

原来担心的是:一台常开的电脑会吵、会费电。插座电量计记了一个月:!!整机待机功耗在 10 瓦左右!!。折算下来每月电费约 6 元,这是 @@可以接受的开销@@,也是 ^^决定让它一直开着的原因^^。

## 一个代码示例

每天早上检查两个服务是否在线的小脚本:

```python
import urllib.request

SERVICES = {"相册": "http://192.168.1.20:2342", "文档": "http://192.168.1.20:8080"}

def check_all() -> dict:
    status = {}
    for name, url in SERVICES.items():
        try:
            with urllib.request.urlopen(url, timeout=5) as resp:
                status[name] = resp.status
        except OSError:
            status[name] = "离线"
    return status
```

行内代码示例:`rsync -a --delete` 每晚把照片同步到第二块硬盘,`cron` 负责定时触发。

## 对照一下数据

| 指标 | 改造前 | 一年后 |
|---|---|---|
| 照片存放位置 | 4 部手机 | 1 台机器 + 1 块备份盘 |
| 找一张旧照片 | 10 分钟以上 | 1 分钟以内 |
| 每月电费增加 | 预计 30 元 | 实际约 6 元 |
